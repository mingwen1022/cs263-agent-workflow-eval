# Employee Onboarding Policy

## Mandatory requirements before first day of work

All new employees must complete the following before starting work:
- background_check
- equipment_setup
- it_access_provisioned

## Mandatory requirements within first 5 business days

- hr_orientation
- compliance_training

## Optional / recommended

- manager_intro_meeting: recommended but not mandatory for access clearance

## Clearance to start

An employee may begin work if all mandatory pre-start requirements are complete.
Outstanding within-5-days requirements should be flagged but do not block start.
