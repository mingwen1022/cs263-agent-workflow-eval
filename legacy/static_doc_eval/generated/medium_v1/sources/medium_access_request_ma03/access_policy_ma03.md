# Data Access Policy

## Analyst role permissions

Analysts may be granted read access to:
- sales_reports
- financial_reports (read only)
- aggregated usage metrics

Analysts may NOT be granted:
- Write access to any report or database
- Access to customer PII databases (requires Data Privacy Officer approval)

## Batch processing

Only requests for the employee under review should be processed.
Requests from other employees included in the same batch export must be excluded.
