# Vendor Selection Requirements

The selected vendor must meet all of the following criteria:

1. **Support response**: four-hour or better response target.
2. **Region**: US region only. EU-region vendors are not eligible for this contract.
3. **Contract length**: at least 12 months.

Select the least expensive vendor that satisfies all requirements.
Report the selected vendor name, monthly price, and any vendors excluded from
consideration with the reason for exclusion.

Risk flags: if only one vendor meets all criteria, flag as single_vendor_dependency.
